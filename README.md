## 🚀 Projects

### **[ONE Student](https://github.com/ONE-Student-WKU/web)** — 원광대 학생을 위한 졸업 도우미
팀 프로젝트 · **리더** · 실제 운영 중 → [onestudent.io.kr](https://onestudent.io.kr)

들은 과목을 넣으면 **졸업까지 무엇이 남았는지** 알려주고, 학칙이 궁금하면 **AI 챗봇이 학칙을 근거로** 답해 주는 서비스입니다.

**이런 걸 할 수 있어요**
- 📋 **졸업요건 진단** — 전공·교양·졸업논문·졸업인증까지 "몇 학점, 무엇이 부족한지" 한 화면에
- 📄 **성적표 PDF 자동 입력** — 학교 성적표 PDF를 올리면 들은 과목이 한 번에 등록
- 💬 **학칙 AI 챗봇** — "전과하면 전공 학점이 줄어?" 같은 질문에 학칙 조항을 근거로 답변
- 🧭 **진로 탐색 · 커뮤니티** — 아직 안 들은 과목으로 진로 로드맵, 스터디·팀원 모집

**시간표·커뮤니티 앱과 다른 점**

| 내 상황 반영 | 없음 | **전과·편입·복수전공·휴학**처럼 학생마다 다른 기준까지 반영 |
| 정보의 근거 | 학생들의 글·후기 | **학교 학칙과 교육과정 책자** 원문, 학교 부서에 직접 확인한 기준 |
